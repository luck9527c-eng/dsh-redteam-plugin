# dsh-redteam-plugin

> 基于 DSH Harness 的**多智能体红队插件**：一个主 agent 专门负责拆解任务、派发任务，其余 agent 各守一条路线干活。

## 这是什么

一支有编制的逆向队伍，而不是一个 agent 从头干到尾。

**主 agent 坐在指挥位**：读目标、把"要回答什么"拆成能证实或证伪的小问题、排两三条候选路线并比较代价与判别力、一条路线派一个工兵、核对回来的事实、按 skill 规则收口归档。它不亲自跑主体考古——例外只有两个：还没法派（要先摸清目标才派得出去），或收口要求复跑。

**成员 agent 是工兵**：一条路线一个人，技术路线与工具由它自己定，干完带着可复跑的证据回来。

## 两个硬性前提

**1. 必须开启 DSH 的智能体团队（Agent Teams）。**
本插件依赖它提供的成员、消息与任务板。没有它，本插件**当场不激活**

**2. 必须配合 `reverse-project-management` skill 使用。**
仓库：<https://github.com/luck9527c-eng/reverse-project-management.git>

它负责项目账目：INDEX、路线与 RUN、证据封存与引用、跨路线复查、项目验收等管理整个逆向工程，方便会话衔接。

## 一次任务怎么流动

```
用户给目标
  │ 主 agent（模式：红队指挥）
  ├─ 拆目标：要回答什么 → 能证实/证伪的小问题 → 两三条候选路线（比代价与判别力）
  ├─ 派任务：一条路线一个工兵；开场简报写清要什么结论、必须交回哪几类锚点、产物落哪、禁止什么
  ├─ 自己不去跑自执行工具（角色闸挡住并给出理由）→ 用这段时间判断下一条路线
  └─ 收口：核对五段回报（结论 / 锚点 / 未解 / 草稿路径 / 下一步）→ 按 skill 规则归档
```

工兵回报里的每个结论都要挂锚点（0x 偏移、RVA/VA、符号、字符串地址、证据 id、RUN-id、文件:行）；拿不出锚点的单独写成「未验证推测」，不与已证结论混排。

## 它和 skill 怎么分工

| | 管什么 |
|---|---|
| **本插件** | 位置：谁能动手、谁能派活、谁读哪套人设；工兵的工具面收窄 |
| **reverse-project-management** | 账目：INDEX、路线/RUN、证据封存与引用、复查、验收、项目恢复 |

## 怎么安装？

要装的是两样东西：**本插件**（让模式列表多出「红队指挥」）和 **`reverse-project-management` skill**（项目账目）。

**直接让AI读 [README_AI](README_AI.md)** 会自动帮你安装好
